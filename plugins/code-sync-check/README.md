# Git / SVN 可用性检查插件

插件包：`code-sync-check.hkp`。宿主要求：小工坊 0.2.0，插件 API 2。

1. 在小工坊「插件管理」中点击安装插件包，选择 `.hkp`。
2. 选择需要同步的沙箱内工作目录；可再选择一个已知仅沙箱内存在的文件。
3. Git、SVN 路径可留空从当前 PATH 查找，或选择目标环境里的实际 exe。不会寻找宿主盘的替代安装，也不会自动下载工具。
4. 先点击「检查版本与目录」，再点击「本地读写自检」。将「复制报告」所得 JSON 提供给后续开发使用。

版本检查只验证本机工具启动与版本输出。可选文件检查由小工坊主进程只读打开一个字节，不输出文件内容。

本地读写自检在所选目录创建唯一 `.handykit-probe-UUID` 临时目录。Git 验证本地 clone/fetch/commit/merge/push 和提交一致性；SVN 使用 `svnadmin` 建立临时 `file://` 仓库，验证 checkout/add/commit/revision/cat 内容。只操作自检创建的数据，不连接真实仓库、不使用真实认证，不提交业务文件。成功清理，失败保留现场并报告路径。

SVN 本地事务检查额外需要 `svnadmin`。缺少它会明确报告该项失败；不等同于 `svn.exe` 不存在，也不证明真实服务器不能连接。

此包是独立安装的**声明式原生能力插件**，不是 DLL、任意 JavaScript 或 Shell 脚本包。宿主按 API 2 提供固定检查能力，插件通过清单选择能力；包内不携带 Git/SVN/Bash。停用后不能执行，卸载只删除插件安装记录，不删除工作目录或自检失败现场。

此插件只验证环境；业务同步由独立的 code-sync 插件完成。环境自检不验证真实远端认证或网络，也不提供进程内 libgit2/libsvn。macOS 本机通过不能替代 Windows/Cloudaemon 实测。
