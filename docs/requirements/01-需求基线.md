# 需求基线 v0.1

## 已确认

- 中文名：小工坊；英文名：HandyKit。
- 个人开发工具集：JSON 格式化、XML 格式化、时间戳转换、cron 表达式处理、定时任务。
- Rust + Tauri（原描述 tarui 按 Tauri 理解），跨平台桌面。
- 区分在线版与离线版；离线安装须解决浏览器运行环境依赖。
- 文档、开发源码、数据库各自独立存放。

## 首版建议与验收

|工具|建议范围|验收条件|
|---|---|---|
|JSON|格式化、压缩、错误定位|合法对象、数组、标量可处理；无效输入保留原文并提示错误|
|XML|格式化、校验|不访问外部实体、DTD或网络；格式化不得悄悄改变文本语义|
|时间戳|秒/毫秒、日期双向转换|明确单位和时区；覆盖负时间戳、非法日期与夏令时边界|
|cron|五字段标准语法、解释、未来触发时间|明确时区和日/月周语义；六/七字段拒绝并解释，不自动猜测|
|定时任务|应用内提醒，手动启停、执行记录|重启后恢复定义；重复触发有去重；关闭应用后不运行|

上述 cron 方言、提醒型任务及关闭行为是建议基线，后续扩展常驻托盘或系统服务须独立设计。首版不默认执行任意 shell 命令。

## 通用约束

数据本地处理，不向远程上传输入；在线/离线指安装依赖获取方式，不代表工具计算是否联网。大文本应设置输入上限并避免阻塞界面。敏感输入默认不记录历史。支持键盘操作、错误反馈和中文界面。
