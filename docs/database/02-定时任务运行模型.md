# 定时任务运行模型 v1

SQL 真源：`database/migrations/0001_initial.sql`。0.2.0 为全新基线，不包含旧提醒表及旧部署迁移。

|表|关键字段/约束|用途|
|---|---|---|
|timer_tasks|id、revision、name、enabled、deleted、config_json、updated_at|完整定义及软删除；所有修改由 Rust 服务串行处理，编辑携带旧 revision 检查冲突|
|timer_runs|id、task_id、revision、source、scheduled_at、started_at、finished_at、status、exit_code、message、stdout、stderr、truncated、snapshot_json|配置快照与执行记录；外键保留任务行，删除任务不级联删除历史|
|timer_run_dispatch|task_id + revision + scheduled_at，仅 source=schedule 唯一|同一版本同一计划触发的持久化去重；手动触发不受此约束|

定义 JSON 包含名称/说明、Cron、IANA 时区、动作类型/目标/解释器、独立参数数组、环境覆盖数组、工作目录、实例策略和可选超时。平台信息不伪造远程执行能力；定义在当前本机执行，保存、启用和实际启动时都核对本机路径。暂停允许目标文件已丢失。

运行状态：running、succeeded、failed、launched、skipped、cancelled、timed_out、interrupted。应用启动的 exit_code 保持 NULL；跳过、超时、取消也不制造成功退出码。计划与实际时间均为 UTC RFC3339，展示时转换任务或系统时区。

领取与执行：进程持有用户目录排他锁；Mutex 内检查启停/版本/重叠/并发并写入 running 或 skipped，登记运行控制器后才在工作线程启动动作。写记录失败不会执行动作；系统接受动作与数据库最终落库之间不具备跨进程事务，崩溃后按未知结果处理，不自动重跑。

初始化：事务内应用 SQL 与 SHA-256 迁移账本，校验未知版本及内容变更。外键、5 秒 busy_timeout、WAL 均启用。启动时将旧 running 标记为 interrupted。定义中的敏感值未加密，运行快照对标记值脱敏；stdout/stderr 不承诺自动脱敏。

保留：最多 30 天和 10000 条历史记录，输出单轮最多 10 MiB，历史输出约 200 MiB；旧输出清空时保留截断标记。正在运行的记录不参与删除。真实库不提交版本管理。
