# 数据库设计（0.2.0）

当前全新基线仅含运行所需的任务领域表，SQL 真源是 `database/migrations/0001_initial.sql`。旧提醒模型的 settings、scheduled_tasks、task_runs 表及跨旧版本升级代码已删除。

| 表 | 用途 |
|---|---|
| schema_migrations | 迁移版本与 SHA-256 校验，事务性初始化并拒绝未知或被篡改的迁移 |
| timer_tasks | 任务定义、配置版本、启停与软删除 |
| timer_runs | 实际执行、状态、退出码、输出和脱敏配置快照 |

SQLite 启用外键、5 秒 busy_timeout 和 WAL。生产文件位于系统用户数据目录 `runtime/handykit.sqlite3`，开发脚本使用 `database/data/`，测试使用临时目录。

定时触发按任务、配置版本、计划时间去重。任务删除不级联清除历史。重启后未结束记录标记为中断，不自动重跑。详细约束见[运行模型](02-定时任务运行模型.md)。

工作区偏好使用 WebView 本机存储；插件配置与历史使用 `runtime/plugins/_data` 中的原子 JSON 文件，不建立重复的 SQL 业务模型。
