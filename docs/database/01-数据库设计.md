# 数据库设计 v0.1

SQLite；时间采用 UTC RFC3339 文本，cron 时区单独保存 IANA 名称。启用外键，运行服务接入时配置 busy_timeout。当前迁移由开发脚本执行，Rust 生产迁移尚未接入。

|表|用途|
|---|---|
|schema_migrations|版本和 SHA-256 校验和，阻止已执行迁移被修改|
|settings|用户配置 JSON 文本，不存输入内容|
|scheduled_tasks|名称、五字段 cron、时区、启停和提醒参数|
|task_runs|计划触发时间、状态及脱敏错误；任务+计划时间唯一用于去重|

SQL 真源为 `database/migrations/0001_initial.sql`。当前不保存 JSON/XML 编辑历史。执行记录保留周期、备份加密及导入导出为后续设计项。

任务删除采用级联删除执行记录；界面须明确提示。生产调度接入时需事务性领取执行权，唯一约束本身不能代替完整执行恢复策略。
