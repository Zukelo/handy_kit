# 小工坊 HandyKit v0.2.0

## 本次发布

- 定时脚本严格使用配置的解释器，Windows 采用普通子进程启动，保留沙箱逻辑路径。
- Git Bash 后台执行不打开独立终端，实时收集标准输出/错误，等待前台脚本完成并记录退出码。
- 独立 API 2 插件：Git/SVN 环境检查，以及 Git → ZIP → SVN 原生同步；支持配置导入、运行记录和定时计划。
- 修复进程管理、Git 环境变量污染、输出路径冲突、执行历史竞争、插件安装中断及标签关闭等问题；完成共享模块与代码规范整理。

## 全新使用基线

0.2.0 使用用户数据目录下独立的 `runtime/`，首次启动没有预设任务和插件；不读取或迁移 0.1.x 旧布局，也不删除旧数据。插件请使用本次发布的 0.2.0 `.hkp` 文件重新安装和配置。

不附带 Bash、Git 或 SVN。脚本与原生同步需要用户本机提供相应工具。stderr 可包含 Git 进度，执行成败以退出码和实际业务结果为准。

## 下载与使用

- Windows x64：online 安装时可下载 WebView2；offline 附带 WebView2 离线安装器；独立 exe 需要系统已具备 WebView2。
- macOS arm64 / x64：DMG，使用系统 WKWebView，当前为 ad-hoc 签名，未进行 Apple 公证。
- Linux x64：deb / AppImage，依赖系统 WebKitGTK，不声明完整自包含离线安装。
- `code-sync-check-0.2.0.hkp`：在插件管理中安装，用于本地 Git/SVN 环境与临时仓库验证。
- `code-sync-0.2.0.hkp`：原生同步插件；先检查并手动验证，再启用唯一业务计划。
- `SHA256SUMS.txt`：所有附件的完整性校验。

Windows 安装包尚未配置代码签名。跨平台构建和自动化检查不代替真实 Cloudaemon 环境的业务验收。先用诊断脚本验证日志、退出码和文件可见性，再运行业务脚本。
