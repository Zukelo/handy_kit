# ADR 0001：技术栈与发行策略

日期：2026-11-20；状态：初始化基线。

用户指定 Rust 与 Tauri，实现跨平台桌面工具集。界面建议 TypeScript + Vite，存储建议 SQLite。

在线和离线为同一源码的发行配置。Tauri 不统一携带 WebKit：Windows 使用 WebView2，macOS 使用系统 WKWebView，Linux 使用 WebKitGTK。当前 Windows 离线包采用 offlineInstaller；Linux 离线交付需要按目标系统验证。

后果：不能承诺所有平台都能单文件、零系统依赖运行；也不能把安装离线等同于构建离线。正式应用标识符需发布前确认。
