# 菜单栏/托盘驻留与品牌图标

日期：2026-11-20。

## 需求与退出语义

- macOS 关闭窗口后留在系统菜单栏；Windows 留在系统托盘；Linux 使用桌面环境的 AppIndicator/托盘。
- 正常关闭主窗口只隐藏窗口，保留当前工具标签及工作区。
- 原生菜单提供「显示主窗口」「隐藏主窗口」「彻底退出小工坊」。只有「彻底退出」真正结束进程。
- macOS 的 Cmd+Q 对应「隐藏到菜单栏」；隐藏时移除 Dock 项，恢复时重新显示。重新打开应用可恢复现有窗口。
- Windows 单击托盘图标恢复，右键显示菜单；macOS/Linux 点击图标显示菜单。
- 托盘创建失败或窗口隐藏失败时，不强制阻止正常退出，避免留下无法恢复的隐藏进程。
- 不增加登录自启动，不启动工具调度或后台业务任务。

Linux 桌面须支持 AppIndicator/系统托盘；部分 GNOME 环境需要桌面托盘扩展。此次未在 Windows/Linux 实机验证，也未实现这两个平台的重复启动单实例协调。

## 实现

Rust 生命周期与菜单逻辑位于：

`development/apps/desktop/src-tauri/src/desktop.rs`

Tauri 启用 tray-icon 特性；关闭事件仅在托盘可用且 hide 成功后调用 prevent_close。app.exit(0) 等程序退出不被拦截。菜单事件统一注册一次，托盘创建失败时应用菜单的退出入口仍可用。

开发版本在系统应用日志目录下记录 desktop.log，内容仅为生命周期事件和进程编号，不含工具输入。macOS 路径为 `~/Library/Logs/dev.handykit.desktop/desktop.log`；正式 release 构建不写此诊断文件。

## 图标设计

主图标改用中文名称的意象：

- 小屋屋檐：表示「坊」，一个随手可用的工作空间。
- 工字工作台：直接回应「工」，兼具开发与制作的含义。
- 小火花：表示灵感与小而有用的工具。
- 绿色底、米色主体、少量金色点缀，与现有工作台配色一致。

源文件：

- `docs/design/brand/handykit.svg`：彩色矢量母版。
- `docs/design/brand/tray-template.svg`：去除底色和火花的单色菜单栏版本。

生成命令：`python3 scripts/generate_icons.py`。使用项目已安装的 Tauri CLI 将 SVG 转为 PNG/ICO/ICNS，复制桌面需要的文件；不依赖在线图片服务。应用内品牌区及文档原型同步使用新图标。

品牌图片以本地资源随 App 打包，Vite 禁用小图片的 data URL 内联，以兼容既有严格 CSP。macOS 菜单栏设置 template 图标，由系统适配浅/深色外观；Windows/Linux 使用彩色图标。
