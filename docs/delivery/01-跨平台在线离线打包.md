# 跨平台在线/离线打包

## 术语

在线版：安装时允许下载缺失的运行依赖。离线版：最终用户断网仍能安装和启动。两者均内置界面资源，工具默认本地运行。构建机可以联网准备依赖；完全离线构建需要另行缓存 npm、Cargo、平台 SDK 及打包工具。

## 平台策略

|平台|在线版|离线版|
|---|---|---|
|Windows|WebView2 downloadBootstrapper|WebView2 offlineInstaller 随安装包携带并按需安装|
|macOS|系统 WKWebView|仍使用系统 WKWebView，不附带私有 WebKit；要求支持的系统版本|
|Linux|系统 WebKitGTK 依赖|按发行版/架构准备依赖包或经验证的运行环境；不能仅凭 AppImage 宣称无依赖离线可用|

Windows 若以后要求应用私有固定运行时，可选 fixedRuntime，但需要下载对应架构运行时、配置路径、承担安全更新维护。当前采用离线安装器，满足断网安装需求，不等于固定私有内核。

## 构建

在 `development/apps/desktop` 中安装依赖后：

- Windows 在线：`npm run build:online`。
- Windows 离线：`npm run build:offline`。
- macOS/Linux：`npm run tauri:build`，离线发布分别核验系统内核或附带依赖介质。

Tauri 默认输出位于 `src-tauri/target/release/bundle`；应分别归档到带有版本、平台、架构和 online/offline 标记的发布目录，避免两次构建产物互相覆盖。签名、标识符和图标尚未配置正式发布值。

## 发布门禁

- Windows 干净虚拟机无 WebView2，断网安装离线包并启动；在线包允许联网安装。
- macOS arm64/x64 分别构建或验证 universal，完成签名、公证与最低系统测试。
- Linux 明确发行版/版本/架构矩阵，缺依赖且断网的机器使用交付介质完成安装。
- 五项工具功能测试；时区与夏令时、迁移升级备份、退出重启恢复测试。
- 校验和、许可证清单、依赖锁文件和安装说明齐备。

当前没有生成或验证任何平台安装包；Linux 自包含离线发行尚未实现。
