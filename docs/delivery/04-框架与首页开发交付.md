# 框架与首页开发交付

日期：2026-11-20。范围：按照 GUI 原型实现可运行的桌面框架与首页，具体工具暂不开发。

## 已实现

- Rust/Tauri 桌面外壳，TypeScript 应用入口；本地界面资源随 App 打包。
- 顶部品牌区、分类导航、可收起侧栏、工具搜索、底部状态栏。
- 固定首页和唯一工具 Tab；打开、切换、关闭、关闭其他、关闭全部；标签溢出横向滚动。
- 首页常用工具、工具箱、收藏筛选、收藏增删、最近打开与清空，以及相应空态。
- Tab、当前页、收藏、最近记录、分类折叠、侧栏与首页筛选在本机持久化。
- 存储不可用时自动退回会话模式，并在状态栏说明；损坏记录和非法工具 ID 不阻止启动。
- 五个工具均接入统一占位页，可返回首页或加入常用工具；应用包不载入原型工具演示代码。

## 代码入口

|位置|职责|
|---|---|

上表以 src 开头的路径均相对于 development/apps/desktop/。

原型仍保存在 docs/prototypes/index.html，使用原有 prototype.js/style.css。原型与应用入口已分开，原型中的 JSON/XML、转换和任务演示不进入应用构建。

## 状态和快捷操作

使用 localStorage 的 handykit.workspace.v2 保存非敏感工作区偏好，兼容读取原型 v1。此阶段不创建 SQLite 生产库；工具数据和调度持久化留待具体工具阶段。

- `/`：展开侧栏并定位搜索；搜索时展开匹配分类，Escape 清空搜索。
- `Alt + H`：回首页（非输入控件中）。
- 在标签上使用左右方向键、Home/End 切换，Delete 关闭；首页固定。
- 标签操作菜单支持键盘上下选择、Escape 关闭并恢复焦点。
- 标签切换记住各自滚动位置；关闭工具时卸载面板。当前无工具输入，因此尚无工具草稿生命周期。

## 本机打包

```sh
cd development/apps/desktop
npm ci
npm test
npm run package:local
```

已有缓存时可用 `npm run package:local -- --offline` 禁止 Cargo 联网解析。首次安装依赖仍需联网。

当前宿主为 macOS Apple Silicon；交付位置：

`builds/darwin-arm64/HandyKit.app`

本地脚本使用当前 Node 和 rustup stable。macOS 构建 debug .app 并完成 ad-hoc 签名，不生成正式 Release，也不触发多平台发布。builds/ 与 target/ 均不提交到 Git。

Windows/Linux 的归档分支已提供，但本轮仅验证 macOS arm64。现有 package:dev 命令保持可用。
