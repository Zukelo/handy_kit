# 桌面交互原型 v0.2

日期：2026-11-20。可打开 [GUI 交互原型](index.html)，不需要安装 npm 依赖；CSS 和 JavaScript 复用开发工程源文件，保持同一份界面。移动文件时应保留仓库相对目录。

## 本轮确认范围

用户要求：默认首页展示常用功能；菜单按功能分类；从菜单进入工具时，在主内容窗口新增类似 IDEA 的标签页。

## 视觉方案

沿用用户提出的 IDE 工作台形式，先采用浅色桌面方案：暖灰背景、绿色强调、紧凑导航与标签、细边框、少量圆角。字体优先使用本机中文字体和等宽代码字体，不下载远程资源。窗口小于 1100px 时首页工具卡片变为两列；小于 850px 时编辑器和转换表单上下排列。目标为桌面，最小内容宽度 740px；Tauri 最小窗口仍为 900×600。

## 首页与菜单

- 首页为固定标签，不允许关闭。
- 常用工具来源于收藏；工具卡片星标可添加或取消收藏。
- 全部工具/我的收藏可切换；最近使用仅记录工具名称，不存工具输入；可清空。
- 左侧分类支持折叠，搜索支持工具名称；按 `/` 聚焦搜索。
- 左侧导航可收起/恢复；工具内容页以面包屑提示当前分类。

## 标签行为

1. 首页卡片或菜单均打开同一个工作区工具标签，不打开独立窗口。
2. 每个工具只保留一个标签；重复点击激活已有标签。
3. 标签可切换、关闭；关闭当前标签时激活左侧相邻标签，首页兜底。
4. 输入在标签切换及关闭重开时于本会话内保留。
5. 右上标签菜单提供「关闭其他工具标签」「关闭全部工具标签」。
6. 标签支持左右方向键、Home/End 导航，Delete 关闭当前工具标签；首页不可关闭。
7. 标签列表、当前标签、收藏、最近工具保存在 localStorage。敏感编辑内容不写入 localStorage，刷新后重置为示例。

## 五个工具页面

|页面|原型可操作项|限制|
|---|---|---|
|JSON|格式化、压缩、校验、示例、清空、复制|浏览器解析，大整数非无损；最大100万字符|
|XML|格式化、校验、示例、清空、复制|不支持 DTD/实体声明；混合文本/xml:space 仅校验；正式算法待接入|
|时间戳|秒/毫秒转日期；日期转秒/毫秒；当前时间|时区仅演示北京时间和 UTC；当前时间需点击刷新|
|cron|五字段展示、预设、未来五次执行预览|只实现工作日09:00、每5分钟、每日零点三种预设；其他表达式明确提示未支持|
|定时任务|新建、启停、确认删除、列表空态|会话模拟数据，无实际调度、通知、数据库持久化；cron 仅检查字段形式|

任务表单使用原生 dialog，支持焦点管理和 Escape 关闭。错误就地显示；复制成功或操作结果用状态提示呈现。
